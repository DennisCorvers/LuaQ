# LuaQ

LuaQ is a reusable Lua library for working with iterables through a fluent
Enumerable API.

## Documentation

See the [LuaQ Wiki](https://github.com/DennisCorvers/LuaQ/wiki) for detailed
guidance on how to use the library and its functions. The Wiki pages were
generated by an AI assistant from the LuaQ source code.

## Usage

Here is a small boss-loot analysis using sample encounter data. It shows how
LuaQ can effectively reduce complex, nested data into just the summary you
want: valuable drops from completed kills, grouped by boss and sorted by total
value. The item values are illustrative, not live prices.

```lua
local LuaQ = require("src.enumerable")

local encounters = {
    {
        boss = "Zamorak",
        result = "kill",
        drops = {
            { item = "Chaos Roar ability codex", value = 18000000 },
            { item = "Onyx", value = 100000 },
        },
    },
    {
        boss = "Rasial",
        result = "kill",
        drops = {
            { item = "Soulbound lantern", value = 42000000 },
            { item = "Spirit weed seed", value = 5000 },
        },
    },
    {
        boss = "Zamorak",
        result = "kill",
        drops = {
            { item = "Bow of the Last Guardian", value = 65000000 },
        },
    },
    {
        boss = "Rasial",
        result = "attempt",
        drops = {},
    },
}

local lootSummary = LuaQ.from(encounters)
    -- Ignore attempts that did not result in a kill.
    :where(function(run) return run.result == "kill" end)
    -- Turn each run's nested drops into a flat stream of valuable drops.
    :flatMap(function(run)
        return LuaQ.from(run.drops)
            :where(function(drop) return drop.value >= 1000000 end)
            :map(function(drop)
                return { boss = run.boss, item = drop.item, value = drop.value }
            end)
    end)
    -- Reduce the drops to one summary per boss.
    :groupByResult(
        function(drop) return drop.boss end,
        nil,
        function(boss, drops)
            return {
                boss = boss,
                valuableDropCount = #drops,
                totalValue = LuaQ.from(drops):sum(function(drop) return drop.value end),
            }
        end
    )
    :sortByDescending(function(summary) return summary.totalValue end)

-- The query yields just the information we need. If materialized with
-- :toTable(), the resulting Lua table would look like this:
-- {
--     { boss = "Zamorak", valuableDropCount = 2, totalValue = 83000000 },
--     { boss = "Rasial", valuableDropCount = 1, totalValue = 42000000 },
-- }
lootSummary:foreach(function(summary)
    print(("%s: %d valuable drops, %d GP total"):format(
        summary.boss,
        summary.valuableDropCount,
        summary.totalValue
    ))
end)
```

With one chain of operations, `flatMap`, `where`, `groupByResult`, `sum`,
`sortByDescending`, and `foreach` transform nested encounter data into a
compact, useful result without manually building intermediate tables.

LuaQ uses deferred execution: creating the query does not sift through the
encounters right away. It starts processing when you ask for the results, such
as by calling `foreach` or `toTable`. This makes it easy to combine steps
without writing a series of loops and building temporary tables yourself.
